### 📂 Ключевые проекты

1. **[Foodgram](https://github.com/AnnBogd/foodgram)** — веб-сервис и REST API для публикации рецептов, подписок на авторов и формирования списка покупок.
   - **Что реализовано:** аутентификация по токенам, фильтрация и пагинация, скачивание списка покупок, админ-панель, мультиконтейнерная сборка (`Docker Compose`: Backend + PostgreSQL + Nginx + Frontend) и CI/CD через GitHub Actions.
   - **Стек:** Python, Django, DRF, PostgreSQL, Docker, Nginx, Gunicorn.

2. **[Animal Shelter](https://github.com/AnnBogd/Animal_shelter)** —  Веб-приложение для приюта животных.
   - **Что реализовано:** каталог животных с фильтрацией, динамический расчет возраста животного, приём заявок на знакомство, отправка emai-сообщений админу при поступлении заявок на знакомство, админ-панель.*
   - **Стек:** Python, Django, SQLite, HTML, Bootstrap.

3. **[Async YaCut](https://github.com/AnnBogd/async-yacut)** — сервис для сокращения URL-адресов и асинхронной загрузки файлов с генерацией ссылок на скачивание.
   - **Что реализовано:** веб-интерфейс и REST API для создания кастомных коротких ссылок, валидация входных данных, конкурентная асинхронная загрузка файлов во внешнее облачное хранилище (Яндекс Диск API), миграции базы данных и автотесты.
   - **Стек:** Python, Flask, SQLAlchemy, Alembic, `asyncio`, `aiohttp`, `pytest`.

4. **[API YaMDb](https://github.com/AnnBogd/api-yamdb)** — REST API для платформы отзывов и рейтингов произведений *(командный проект - тимлид)*.
   - **Моя роль:** CRUD-функционал для отзывов, комментариев, расчёт рейтинга, работа с Git-ветками и разрешение конфликтов слияния, связь команды с ревьюером, помощь команде в решении проблем и поиск решений.
   - **Стек:** Python, Django, DRF, SimpleJWT, PostgreSQL/SQLite, Git.
